## 已有本机演示包

此节只供已持有`知阅-本机运行版-20261017-M25`目录的用户使用，源码下载不含该目录。
普通Windows资源管理器双击`启动.cmd`，窗口出现READY后保持打开，
访问 <http://127.0.0.1:5179/books>，后端18085。
在启动窗口输入`q`并回车，等待STOPPED后退出；再次使用时双击同一入口。
运行依赖该本机的Java、Node、既有MySQL及配置；不要同时启动多个运行包。

M25前端对应`6fc96ed`业务代码，后端JAR与启动器沿用M15。
22份关键源码和35份运行文件已与装配指纹核对一致。
文档更新、Git合并和CI成功不表示已替换该运行包，也不表示服务此刻在线。
