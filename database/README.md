# 数据库结构

本发布副本仅提供 schema.sql，含 6 张表及相关索引，不包含原始用户记录或演示账号。

使用 MySQL 8 客户端连接独立测试数据库后执行 SOURCE database/schema.sql（路径按本机位置调整）。脚本会创建 ebook_recommend_db；只在首次初始化的空库执行，重复执行索引语句可能报重名错误。不要对唯一业务数据库执行。

初始化后图书列表为空。通过注册页面创建自己的测试账号，密码使用 BCrypt；如需演示图书，请在本机测试库添加虚构书籍，勿上传真实用户数据。

复制 .env.example 为本机 .env，设置自己的连接信息。CI 使用 H2，不需要真实 MySQL 密码。

结构提取已检查表名与无数据写入语句；本次未在新 MySQL 实例执行 schema.sql，初始化兼容性待实际验证。
